# CONTRIBUTORS.md — Contributeurs de KalanCode

Merci à toutes les personnes qui ont contribué à KalanCode ! Ce projet existe grâce à vous. 🙏

---

## Comment apparaître ici ?

Toute personne ayant soumis une Pull Request acceptée, un rapport de bug, une traduction, une relecture ou une contribution documentaire est éligible à figurer dans ce fichier.

Pour ajouter votre nom :
1. Ouvrez une Pull Request avec vos informations dans le tableau ci-dessous
2. Précisez votre contribution dans la description de la PR

## Types de contributions reconnues

- 💻 **Code** — Implémentation de fonctionnalités, corrections de bugs
- 📖 **Documentation** — README, guides, spécifications
- 🌍 **Traduction** — Bamanankan, N'Ko, Français et autres langues
- 🎨 **Design** — UI/UX, illustrations, icônes
- 🔍 **Revue** — Relecture linguistique et pédagogique
- 🐛 **Bugs** — Signalement et reproduction de bugs
- 💡 **Idées** — Suggestions de fonctionnalités via les issues
- 📣 **Promotion** — Articles, présentations, partages
