# learning/ — Contenus pédagogiques KalanCode

Ce dossier regroupe tous les **contenus d'apprentissage** de KalanCode : modules, leçons, glossaires et ressources pédagogiques.

---

## Philosophie

KalanCode enseigne la programmation et la cybersécurité **en Bamanankan (latin) et en N'Ko**, les langues du peuple Mandé. Les contenus sont conçus pour être :

- **Accessibles** : pas de prérequis informatique
- **Culturellement ancrés** : exemples tirés du quotidien africain
- **Communautaires** : relus et validés par des locuteurs natifs
- **Découplés du code** : facilement modifiables sans toucher à l'application

---

## Structure

`
learning/
├── README.md            ← ce fichier
├── modules/             ← parcours thématiques complets
│   ├── informatique-base/
│   ├── algorithmes/
│   ├── cybersecurite/
│   └── ...
├── glossaire/           ← termes techniques traduits
└── ressources/          ← liens, références, bibliographie
`

> **Note MVP** : Pour la phase MVP, les contenus pédagogiques sont directement intégrés dans le code source de l'application (rontend/src/data/). Ce dossier learning/ est prévu pour accueillir les contenus **hors-code** au fur et à mesure que la communauté grandit.
