# Contribuer à KalanCode

Merci de contribuer à un apprentissage de la programmation et de la cybersécurité plus accessible.

## Avant de contribuer
- Lisez `README.md` et `docs/PRODUCT_SPEC.md`.
- Pour une traduction, indiquez la variante d'écriture et la personne ayant relu le texte.
- Ne présentez pas une traduction incertaine comme validée.
- N'ajoutez pas de code qui exécute du code apprenant sans revue de sécurité.

## Types de contributions
- Leçons et exercices
- Relecture linguistique
- Relecture pédagogique ou technique
- Interface et accessibilité
- Tests et documentation
- Signalement de bugs

## Processus
1. Ouvrez une issue pour discuter d'un changement important.
2. Décrivez le problème et la solution proposée.
3. Ajoutez ou mettez à jour les tests nécessaires.
4. Soumettez une pull request.
5. Attendez les revues requises avant publication.

## Licences
Les licences du code et des contenus pédagogiques doivent être définies et affichées avant d'accepter des contributions destinées à la publication.
